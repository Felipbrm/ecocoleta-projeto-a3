## 🌍 Sobre o Projeto
O **EcoColeta** é uma plataforma web responsiva desenvolvida para facilitar o descarte consciente e a reciclagem de resíduos urbanos. O projeto liga cidadãos a cooperativas de reciclagem, tornando o processo de recolha simples e eficiente.

Este trabalho responde diretamente aos **Objetivos de Desenvolvimento Sustentável (ODS) da ONU**:
- **ODS 11:** Cidades e Comunidades Sustentáveis.
- **ODS 12:** Consumo e Produção Responsáveis.
